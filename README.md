# Weather Ensemble — канал обновлений Android

В этом открытом репозитории находятся только установочные APK, описания выпусков и `forecast.json` для приложения. Исходный код, сырые измерения станций и ключи хранятся отдельно в закрытом `special-nine/weather`.

`forecast.json` публикуется после проверки полного сохранённого прогноза двух городов. Он содержит 24 будущих часа пяти моделей и краткие результаты независимой сверки прошедших периодов. Данные физической станции не выдаются за измерение в городе: в файле указаны станция, координаты и расстояние. 12-часовая сумма остаётся 12-часовой. Вероятность дождя не калибрована и не публикуется.

Прогнозы моделей: [Open-Meteo](https://open-meteo.com/), CC BY 4.0. Станционные данные: Гидрометцентр России, Meteostat и архив RP5; в публичном файле нет их сырого ряда. Проект личный и некоммерческий.

Приложение проверяет [последний выпуск](https://github.com/special-nine/weather-updates/releases/latest) при открытии, сверяет размер и SHA-256 установочного файла и передаёт его системному установщику Android. Установка требует подтверждения владельца телефона.

Публикация APK выполняется GitHub Actions после поступления подписанного файла из закрытого проекта. Постоянный ключ подписи не хранится здесь.
