Первый выпуск с постоянной подписью для последующих обновлений поверх установленной версии.

- Новый экран прогноза для Подольска и Чехова: ближайший час, 24-часовая лента и сводка по дням.
- Автоматическое обновление прогноза при открытии и каждые 30 минут, пока приложение запущено.
- Отдельный показ сохранённого выпуска и независимой сверки с физическими станциями, с указанием расстояния до города.
- Проверка новой версии приложения при открытии; загрузка APK с проверкой SHA-256, установка через системное подтверждение Android.

Проверенная вероятность дождя пока не публикуется. Данные удалённых станций не считаются точным фактом для города.
